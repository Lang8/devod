# Deutsch Trainer

독일어 시험 대비를 위한 개인화 독해 및 어휘 학습 서비스

## 1. 프로젝트 소개

Deutsch Trainer는 독해 콘텐츠를 기반으로 사용자가 모르는 단어와 표현을 직접 수집하고, 이를 개인화된 단어장으로 축적하는 학습 서비스다.

기존 단어장 서비스처럼 미리 정해진 단어를 암기하는 방식이 아니라, 실제 독해 과정에서 마주친 어휘를 기록하고 반복적으로 복습하는 것을 핵심으로 한다.

특히 독일어의 특성을 고려하여 단어의 의미뿐 아니라 명사의 성별, 복수형, 동사 변화, 문맥에 따른 의미 등 구체적으로 부족한 지식을 구분하여 관리하는 것을 장기적인 목표로 한다.

### 핵심 가치

- 주제별 독해 콘텐츠 제공
- 독해 중 모르는 단어와 표현을 간편하게 수집
- 수집한 단어를 기반으로 개인화된 단어장 자동 생성
- 주제별 어휘 분류 및 관리
- 단어의 형태 변화와 문맥을 함께 기록
- 사용자가 부족한 지식 요소를 구분하여 복습

---

## 2. 서비스 방향

서비스는 독해를 중심으로 학습 데이터가 축적되는 구조를 가진다.

기본 학습 흐름은 다음과 같다.

1. 사용자가 학습하고 싶은 주제를 선택한다.
2. 선택한 주제와 수준의 독해 지문을 제공받는다.
3. 문장을 읽으면서 모르는 단어 또는 표현을 선택한다.
4. 해당 단어의 모르는 이유를 기록한다.
5. 선택한 단어와 발견 문맥이 개인 단어장에 저장된다.
6. 축적된 단어를 주제별로 확인하고 복습한다.

**핵심은 독해 콘텐츠가 개인 단어장을 만드는 출발점이라는 것이다.**

---

## 3. 독해 콘텐츠

### 3.1 주제별 독해

독해 콘텐츠는  다양한 주제를 제공한다.

초기 주제 예시:

| 주제 | 독일어 |
|---|---|
| 환경 | Umwelt |
| 동물 | Tiere |
| 경제 | Wirtschaft |
| 생활 | Alltag |
| 직장 | Arbeitswelt |
| 교육 | Bildung |
| 건강 | Gesundheit |
| 사회 | Gesellschaft |
| 정치 | Politik |
| 디지털화 | Digitalisierung |
| 문화 | Kultur |
| 과학 | Wissenschaft |

하나의 지문은 장문 독해 콘텐츠 하나를 기준으로 한다.

지문은 문장 단위로 구분하여 학습할 수 있어야 한다.

### 3.2 문장별 독해

각 문장은 독립적으로 확인할 수 있어야 한다.

기본 제공 정보:

- 독일어 원문
- 한국어 번역
- 지문 내 문장 순서
- 문장에 포함된 단어 및 표현

한국어 번역은 필요에 따라 표시하거나 숨길 수 있도록 확장한다.

### 3.3 독해 중 단어 수집

사용자가 독해 중 모르는 단어를 직접 선택하여 개인 단어장에 추가할 수 있어야 한다.

지원할 인터랙션:

- 단어 클릭
- 여러 단어 드래그 선택
- 숙어 및 구문 단위 선택
- 선택한 단어의 학습 상태 지정

기본 인터랙션은 클릭 방식으로 구현하고, 드래그 선택은 숙어나 여러 단어로 구성된 표현을 수집하는 용도로 활용한다.

## 4. 개인화 단어장

### 4.1 기본 개념

단어장은 AI가 미리 제공하는 고정된 단어 목록이 아니다.

사용자가 독해 과정에서 실제로 마주치고 수집한 단어와 표현을 중심으로 구성된다.

단어 기본형과 실제 발견 형태를 구분하여 관리한다.

예시:

| 발견한 형태 | 기본형 | 의미 |
|---|---|---|
| vermieden | vermeiden | 피하다 |
| trägt | tragen | 운반하다, 입다 |
| gegangen | gehen | 가다 |
| geschrieben | schreiben | 쓰다 |
| wäre | sein | ~일 것이다 |

동일한 단어가 여러 지문에서 발견되더라도 기본 단어장은 중복 생성하지 않는다.

대신 각각의 발견 기록과 문맥을 보존한다.

### 4.2 단어 정보

단어별로 다음 정보를 관리한다.

- 독일어 기본형(Lemma)
- 품사
- 한국어 의미
- 관사 및 성별(명사)
- 복수형(명사)
- 동사 변화 정보
- 형용사 및 부사의 변화 정보
- 유사어 및 반의어
- B2 수준 정보
- 관련 주제
- 예문

### 4.3 발견 기록

단어 자체의 정보와 사용자가 실제로 발견한 기록은 분리한다.

발견 기록에는 다음 정보를 저장한다.

- 실제 발견한 단어 형태
- 발견한 독해 지문
- 단어가 포함된 원문 문장
- 발견 날짜
- 해당 지문에서의 문맥
- 당시 사용자가 선택한 학습 상태

이를 통해 사용자는 단어장에서 해당 단어를 처음 만났던 문장을 다시 확인할 수 있다.

### 4.4 주제별 분류

단어는 다음과 같은 주제별로 분류한다.

- 환경
- 동물
- 경제
- 생활
- 직장
- 교육
- 사회 등

하나의 단어가 여러 주제에 속할 수 있도록 설계한다.

예를 들어 Umwelt에서 발견한 단어가 Wirtschaft 지문에서도 등장한다면 두 주제 모두에 연결할 수 있어야 한다.

### 4.5 단어장 필터

단어장 상단에는 다음과 같은 분류 필터를 제공한다.

- 모르는 단어
- 숙어 및 표현
- 자주 등장하는 단어
- 전체 단어

이후 주제별 필터와 결합하여 사용할 수 있어야 한다.

## 5. 모르는 이유 및 학습 상태 관리

### 5.1 설계 목적

단순히 모르는 단어라는 하나의 상태만으로는 사용자의 실제 취약점을 파악하기 어렵다.

독일어는 단어의 의미를 알고 있어도 성별이나 복수형을 모를 수 있고, 문장에서의 활용이나 문맥상 의미를 이해하지 못할 수도 있다.

따라서 하나의 단어에 여러 학습 상태를 동시에 등록할 수 있도록 설계한다.

### 5.2 학습 상태 유형

초기 상태 유형은 다음과 같이 정의한다.

| 코드 | 상태 | 설명 |
|---|---|---|
| UNKNOWN | 처음 보는 단어 | 단어 자체를 모름 |
| UNFAMILIAR | 익숙하지 않은 단어 | 본 적은 있지만 정확히 기억나지 않음 |
| MEANING | 의미를 모름 | 단어의 뜻을 모름 |
| GENDER | 성별을 모름 | der / die / das를 모름 |
| PLURAL | 복수형을 모름 | 명사의 복수형 변화를 모름 |
| INFLECTION | 형태 변화를 모름 | 격변화, 동사 활용 등을 모름 |
| CONTEXT | 문맥을 이해하지 못함 | 특정 문장에서의 의미를 모름 |
| EXPRESSION | 표현을 이해하지 못함 | 숙어 및 관용 표현을 모름 |

위 상태는 서로 배타적이지 않다.

예를 들어 `die Entscheidung`이라는 단어에 대해 사용자는 성별과 복수형을 동시에 모른다고 기록할 수 있다.

### 5.3 학습 상태 UX

초기에는 단어를 선택한 뒤 팝오버에서 상태를 선택하는 방식을 사용한다.

향후 다음과 같은 인터랙션을 지원할 수 있도록 설계한다.

- 일반 클릭: 기본 단어 등록
- Ctrl + 클릭: 상세 학습 상태 선택
- 드래그: 여러 단어 및 숙어 선택
- Ctrl + 드래그: 선택 영역에 상세 학습 상태 지정
- 숫자 키: 학습 상태 빠른 선택

숫자 키는 상세 상태를 빠르게 토글하는 용도로 사용한다.

여러 학습 상태를 동시에 선택할 수 있어야 한다.

모바일에서는 키보드 단축키 대신 선택 영역의 팝오버를 통해 동일한 기능을 제공한다.

### 5.4 학습 상태 변경 이력

사용자가 처음 등록한 학습 상태와 이후 해결한 상태를 구분할 수 있어야 한다.

예시:

1. 처음에는 명사의 성별을 모름.
2. 복습 후 성별을 알게 됨.
3. 복수형은 여전히 모름.
4. 이후 복수형도 학습 완료.

학습 상태를 단순히 덮어쓰는 것이 아니라 해결 여부와 변경 이력을 추적할 수 있도록 확장성을 확보한다.

## 6. 독일어 형태 분석

독일어는 단어의 문법적 형태가 문장에 따라 달라지므로 사용자가 발견한 형태를 기본형과 연결하는 기능이 중요하다.

### 6.1 기본형 자동 변환

예를 들어 사용자가 `vermieden`을 선택하면 기본형인 `vermeiden`으로 연결한다.

이때 실제 발견 형태인 `vermieden`도 별도로 보존한다.

### 6.2 지원 대상

- 동사 원형 및 활용형
- 명사의 격변화
- 명사의 복수형
- 형용사의 어미 변화
- 분리동사
- 불규칙 동사
- 복합어

### 6.3 문맥 기반 분석

동일한 형태라도 문맥에 따라 의미와 문법적 역할이 달라질 수 있다.

따라서 단순한 사전 검색만으로 기본형과 의미를 결정하지 않는다.

형태소 분석을 우선 활용하고, 문맥에 따라 의미가 불분명한 경우 AI를 활용하여 보완한다.

자동 분석 결과가 불확실할 때는 사용자가 직접 수정할 수 있는 구조를 고려한다.

## 7. 퀴즈 및 복습

수집한 단어를 활용하여 개인화된 복습 기능을 제공한다.

### 초기 기능

- 독일어 단어를 보고 한국어 의미 맞히기
- 한국어 의미를 보고 독일어 단어 맞히기
- 객관식 문제
- 빈칸 채우기
- 발견했던 예문을 활용한 문제

### 향후 확장

학습 상태에 따라 문제 유형을 다르게 출제한다.

예시:

| 학습 상태 | 복습 방식 |
|---|---|
| MEANING | 단어의 의미 맞히기 |
| GENDER | 명사의 관사 맞히기 |
| PLURAL | 복수형 맞히기 |
| INFLECTION | 문장에 맞는 활용형 선택 |
| CONTEXT | 기존 문장의 의미 해석 |
| EXPRESSION | 숙어 및 표현의 의미 맞히기 |

단어의 모든 정보를 매번 테스트하는 것이 아니라 사용자가 부족하다고 기록한 요소를 중심으로 출제하는 것이 목표다.

## 8. 설계 원칙

향후 기능 확장을 고려하여 다음 원칙을 준수한다.

1. 단어 기본 정보와 사용자별 학습 기록을 분리한다.
2. 단어의 기본형과 실제 발견 형태를 분리한다.
3. 하나의 단어에 여러 발견 기록을 연결할 수 있어야 한다.
4. 하나의 단어가 여러 주제에 속할 수 있어야 한다.
5. 하나의 단어에 여러 학습 상태를 동시에 지정할 수 있어야 한다.
6. 학습 상태의 해결 여부와 변경 이력을 관리할 수 있어야 한다.
7. 학습 상태 종류를 추후 추가할 수 있도록 설계한다.
8. AI 생성 콘텐츠와 사용자 학습 데이터를 분리한다.
9. 자동 형태 분석 결과는 수정 가능해야 한다.
10. 독해와 단어장, 복습 기능이 동일한 단어 데이터를 공유해야 한다.

## 9. 프로젝트의 장기적인 목표

Deutsch Trainer는 단순한 독일어 단어장이나 AI 문제 생성 서비스가 아니다.

독해 과정에서 축적한 개인별 어휘 데이터와 학습 취약점을 기반으로 학습 경험을 개인화하는 것이 궁극적인 목표다.

장기적으로는 다음과 같은 방향으로 발전시킨다.

- 개인별 어휘 수준 분석
- 취약한 문법 요소 분석
- 주제별 어휘력 분석
- 개인화된 독해 콘텐츠 추천
- 수집한 어휘를 활용한 작문 연습
- 시험 유형별 독해 및 작문 훈련
- 개인별 취약 영역에 맞춘 학습 계획

**최종 목표: 사용자가 독일어를 읽으며 마주친 모든 어려움을 기록하고, 그 기록을 바탕으로 자신에게 필요한 학습을 제공하는 개인화 독일어 학습 서비스.**
